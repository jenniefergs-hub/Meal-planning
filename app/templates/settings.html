Google Cloud Vision API key (for importing recipes from photos, recommended)

Noticeably more accurate than OCR.space below, especially on trickier photos. Uses the same Google Cloud project as Gmail: in Google Cloud Console, enable the Cloud Vision API (APIs & Services → Library → search "Cloud Vision API" → Enable) — this requires linking a billing account (card) to the project, but the free tier (1,000 images/month) comfortably covers personal use, and you can set a budget alert in Billing as a safety net. Then create an API key (APIs & Services → Credentials → Create Credentials → API key) — optionally restrict it to just "Cloud Vision API" under API restrictions — and paste it below.

If both this and the OCR.space key below are set, Google Cloud Vision is used.

OCR.space API key (for importing recipes from photos, free alternative)
